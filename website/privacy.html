Privacy

Last updated July 9, 2026

The app

  • No account, no sign-in, no analytics, no telemetry. There is no server side.
  • Files you drop on the shelf are stored as local security-scoped bookmarks. They never leave your Mac.
  • Settings live in your local Application Support folder.
  • System permissions (Calendar, media control via Automation) are requested on first use and can be revoked in System Settings at any time.
  • Some modules fetch public data over the network when you enable them: the Stocks page requests market quotes and GitHub trending lists, and Now Playing can request lyrics for the current track. These requests carry no personal identifiers beyond what any HTTP request includes.
  • The Code page runs command line tools you already installed (Claude, Codex, Cursor). Their network behavior is governed by their own vendors' policies.

This website

  • Static files, served as is. No cookies, no analytics, no tracking pixels, no embedded third-party scripts.
