Does it work with fullscreen apps?

Yes. The panel uses auxiliary panel behavior, so it appears over a fullscreen Space without becoming a separate app window.

Does it cover the camera?

No. The interface is shaped around the hardware notch. It never covers the camera, the sensor housing, or the privacy light.

What do the Code panes need?

Install the matching command line tools. Topsoil resolves Claude, Codex, and Cursor (including Cursor's cursor-agent) from your shell paths.

What about a Mac without a notch?

It still runs. When no physical notch is detected, the panel anchors to the top center of the main display.

Are dropped files uploaded?

No. Drop Shelf keeps local references only. Your files stay where they are unless you move them.
