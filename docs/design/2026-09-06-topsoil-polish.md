# Topsoil experience refresh

Topsoil is a native Mac utility shelf. Its defining gesture is a compact notch opening into a useful workspace. Keep that gesture and the user's existing module selection.

Direction: a precise dark instrument panel, restrained cyan from the user's chosen accent, brighter labels, rounded SF display typography, and softer inset cards. Named page navigation replaces anonymous dots. Search finds enabled tools immediately. Layout preferences become functional: paged tiles, a wider lead tile, or one focused module per page.

Settings gets a branded sidebar, section descriptions, a searchable module library with useful descriptions, and real interaction guidance in place of placeholders. Preserve native controls, existing persistence, permissions, module order, and user themes.

Validate the navigation planner with empty, filtered, mixed full-width, and focus layouts; run the existing suite; render and inspect dashboard, alternate pages, compact, wide bar, and settings. Package a local build for review.

## Visual revision after desktop review

The first pass still looked like a control panel on the user's light desktop. Revised to a 1120 × 350 panel with a near-opaque charcoal base, softer borderless cards, proportional interface type, and bounded widths for sparse pages. The timer now presents its duration prominently with a compact Start action. The garden uses a square canvas and a full-height card aligned with the three terminal panes, with simpler Water/Feed actions and readable metrics. Terminal text retains its code typography. The notch explicitly uses dark color semantics for native fields.

Validation: 418 checks passed; dashboard and plant alignment inspected in the running packaged app; snapshot previews saved alongside this document.
